# BTC Bot (Connors-long 30m, Binance Testnet)

Скелет торгового бота для forward-тесту стратегії. Починаємо з одного компонента
(Connors RSI(2) long 30m) для перевірки "сантехніки", архітектура — під додавання
решти стрімів конфігурації D.

## Встановлення
```bash
pip install ccxt pandas numpy
```

## Налаштування
1. Зареєструйся на https://testnet.binancefuture.com/ → отримай API Key/Secret.
2. Встав їх у `config.py` (або через env: `BINANCE_API_KEY`, `BINANCE_API_SECRET`).
3. Перевір `USE_TESTNET = True` (безпечно, паперові гроші).

## Запуск
```bash
python bot.py
```
Спочатку постав `DRY_RUN = True` — бот лише логуватиме сигнали, не шлючи ордери.
Переконайся, що сигнали з'являються логічно, тоді `DRY_RUN = False` на testnet.

## Що перевіряємо на цьому етапі (сантехніка)
- бот підключається до біржі, бачить баланс
- коректно ловить закриття свічки (без зазирання в майбутнє)
- рахує розмір позиції під заданий ризик
- виставляє/закриває ордери, переживає рестарт (стан у `bot_state.json`)

## Додавання стрімів конфігурації D
У `strategies.py` успадкуй `Strategy`, реалізуй `should_enter`/`should_exit`,
додай у `ACTIVE_STRATEGIES`. Пропиши ризик у `config.RISK_PER_TRADE`.
Наступні компоненти: ConnorsShort30m, Trend-VBT (4H), Mom (1H/2H), Bear-календар (1D).

## ВАЖЛИВО
- Це forward-тест, а НЕ продакшн. Очікувана дохідність наживо ~половина бектесту.
- Реальні гроші — лише після 1-3 міс. успішного testnet-тесту.
- Бот використовує market-ордери; на реальному рахунку враховуй слиппедж.
