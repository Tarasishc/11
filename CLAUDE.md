# Правила для Claude

## Автоматичні git операції

Після кожної успішної зміни коду **автоматично** виконувати без запиту дозволу:

```bash
git add .
git commit -m "<осмислене повідомлення українською>"
git push -u origin <поточна-гілка>
```

### Вимоги до commit-повідомлень:
- Писати **українською мовою**
- Коротко і чітко описувати суть змін
- Приклади: "Додано компонент кнопки", "Виправлено помилку в формі входу", "Оновлено стилі головної сторінки"

### Важливо:
- **Не питати дозволу** на виконання git команд
- Виконувати після кожного успішного завершення задачі
- Якщо push не вдається через мережеву помилку — повторити до 4 разів з затримкою (2с, 4с, 8с, 16с)
